# DSTU-Chat (Python 3)

Незаконченный мини-чат, фишкой которого является отправка сообщений (и потенциально файлов) в «зашифрованном» виде по примеру полинома Чебышева. Теперь серверная часть переписана на Python 3.

## Требования

- Python 3.10+
- `pip install flask`

## Запуск

```bash
cd Project1
python3 -m venv .venv
. .venv/bin/activate
pip install flask
python app.py
```

После запуска сервер доступен по адресу `http://127.0.0.1:5000/`, откуда сервируются статические файлы `index.html`, `chat.js` и остальные ресурсы.

## Структура

- `app.py` — Flask-приложение, обрабатывающее действия `getState`, `update` и `send`.
- `chat.txt` — файл-журнал сообщений.
- `index.html`, `chat.js`, `style.css` — фронтенд-приложение.
